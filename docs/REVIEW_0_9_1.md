# 0.9.1 多角度审核与修复

审核范围包括自定义卡组编辑与分享、选牌往返、原生效果与暂停恢复、动作事件、双方视角的 3D 动画、联机校验及 AI 私有信息边界。保留原有前台配色和横向布局，卡池仍为 341 张、预设仍为 14 套，协议仍为 7。

## 已修复的问题

| 级别 | 问题与影响 | 修复 |
| --- | --- | --- |
| P1 | 构造搜寻选择时，一边读取候选数量、一边移动候选数组。Windows C++ 参数求值顺序使上限变成 0，招式学习器进化和戴鲁比附能无法选择实际卡牌。 | 先计算选择上限，再移动数组；用实际进化和附能结果验证，避免只检查招式“执行成功”。 |
| P1 | 退化后立即昏厥的宝可梦，在动作前快照里仍是进化叠放中的卡，事件推导无法识别，击倒提示可能指向攻击方。 | 识别退化后成为场上宝可梦的卡；先显示下层形态，再在正确位置播放昏厥和离场。 |
| P2 | 可取消动作的事件一直积压到后续选择全部结束，导致撤退先在状态中完成、动画却延迟到对手弃牌后重放。 | 进入不可取消或对手所有的选择时提交动作，先发布已完成动作的事件，结束该取消检查点。 |
| P2 | 新效果把战斗场／备战位写成区域名，部分进化、附能和非昏厥弃置仅有通用通知，缺少正确动画来源或附件身份。 | 区分区域与场上位置，补齐能量／道具角色；进化、附能使用对应事件，备战缩减按宝可梦及其附件发出离场事件。 |
| P2 | 编辑数量时重建所有卡池控件和清单行，产生不必要的控件分配，丢失控件身份与当前交互状态。 | 增量更新数量，仅新增或删除实际变化的行，保留滚动和重复点击目标。 |
| P2 | 从选牌页进入编辑器未打开当前浏览的卡组；返回时双方分配及弱点／抗性设置被重置。 | 携带并恢复编辑上下文；非法草稿保留选择但禁用开局，删除的卡组清空槽位，不替换成其他预设。 |
| P2 | 第一次保存没有备份；允许导出超过导入长度限制的分享码。 | 首次写入即生成可恢复备份；导出使用相同长度边界，超限显示明确原因。 |
| UI | 清单中的同名异画难以区分，构筑问题只能通过截断文本或鼠标悬停查看；空筛选缺少提示。 | 增加缩略图、印刷编号、稀有度及分类分组；支持点击查看完整问题、清除筛选和空状态说明。 |
| UI | 紧凑横屏中卡图高度与操作按钮争夺空间；可选攻击效果误用“发动特性”文案。 | 卡图高度根据实际可用空间调整，保证首排加入按钮完整可见；按效果上下文显示确认文案。 |
| UI | 80 字卡组名会把下拉框最小宽度撑到 1571 逻辑像素，挤出其他编辑操作；长系列名称也有同样风险。 | 卡组和筛选下拉框启用文本裁切与省略，名称输入仍保留完整内容，并加入长文本边界回归。 |

## 回归入口

- deck_editor_interaction_contract.gd：首次损坏恢复、分享上限、控件身份、滚动、筛选及选牌状态恢复。
- deck_editor_visual_contract.gd：1600×900、1280×800、900×540、800×480 实际渲染；48 像素触控目标、连续加减、滚动、完整违规信息、返回提示和编辑入口。
- csv5_presentation_contract.gd：真实搜寻结果、区域／位置、附件角色、事件提交时机和退化昏厥目标。
- csv5_animation_contract.gd：28 个真实规则到画面的场景，覆盖双方视角与 cinematic／standard／fast／reduced 模式，检查进化落地时机、退化后形态、昏厥对象、非昏厥离场、动画结束清理及对手手牌隐藏。
- custom_deck_privacy_contract.gd：私有卡表投影、非法卡表、指纹、重连换牌和固定随机种子的 AI 不变性。

实际渲染截图位于 build/deck-editor-preview 和 build/csv5-animation-review，动画验证记录位于后者的 validation.json。

Android ARM64 构建与 APK 静态校验可以在本机执行；没有连接 Android 设备，真机运行、软键盘与真实触控未验证。

## 本地验证结果（2026-10-10）

- 原生规则、117 个 Challenge 战术场景、搜索状态与预算测试通过。
- 标准回归通过：45 项 Godot 契约及 16 场 LAN／Relay 完整对局，覆盖预设、自定义、镜像、重连、非法卡表与隐私隔离。
- AI 回归通过：14 套预设和 3 场预设 AI 对抗新卡自定义卡组，共 17 场完整对战。
- 前台实际图形回归通过；编辑器覆盖四种尺寸、连续点击与触控滚动。性能基准未重跑。
- 28 个新增战斗动画场景通过，并人工检查了编辑器截图、道具进化、退化后昏厥的飞行与结算画面。
- 内容编译与生成检查通过：341 张、14 套预设、478 个效果、99 个 VM 操作；内容指纹未变化，规则指纹更新。
- Windows／Android 的 debug 与 release 原生库均已重新编译。
- 最终双平台导出、自检与发布包检查通过：Windows 启动、原生 AI、Protocol 7、Android 测试签名与 ARM64 载荷，以及 5 项分发文件校验和均通过；Android 设备运行明确跳过。
