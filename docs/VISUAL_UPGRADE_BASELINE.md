# Godot 0.3.x 视觉升级基线

## 目标

Godot 版本以 Pygame 已有表现为最低覆盖线，并在信息层级、响应式布局、操作反馈、联机一致性和无障碍设置上超过它。规则语义、AI 决策和协议 v3 不因表现层重构而改变。

## 功能矩阵

| 项目 | Pygame 基线 | Godot 0.3.x |
|---|---|---|
| 标题与模式入口 | 基础背景与按钮 | 动态抽象背景、卡牌陈列、清晰模式层级 |
| 牌组选择 | 文字与封面信息 | 真实卡图预览、属性色和响应式卡片 |
| 牌桌 | 卡图棋盘 | 原创桌垫、双方区域光晕、完整牌区和安全区适配 |
| 场上信息 | HP、伤害和基础标记 | HP、伤害、能量、道具、状态、进化和操作提示叠层 |
| 手牌 | 横向卡牌 | 响应式扇形/重叠布局、选中抬升、超宽屏增距 |
| 操作 | 按钮/点击 | 上下文命令、合法目标高亮、长按详情、可选拖拽和辅助动作面板 |
| 复杂选择 | 文字选项 | 卡图网格、计数、目标高亮和隐藏信息过滤 |
| 动画 | 卡牌移动和基础反馈 | 事件队列、弧线飞行、进化、攻击、命中、治疗、换位、击倒和奖品 |
| 音频 | 基础音效 | Master/Music/SFX/UI 分层、三套原创循环和主要动作音效 |
| 联机表现 | 状态刷新 | 协议 v3 可选表现事件、观察者过滤、去重和重连清队列 |
| 可访问性 | 基础音量 | 四种动画速度、减少动画、四种画质档、全动作兜底入口 |
| 视觉回归 | 手工观察 | 固定场景和固定尺寸自动截图 |

## 设计与资源规范

- 使用既有发布卡图；隐藏信息只显示统一卡背。
- UI 背景、桌垫、光效、粒子和程序化音频均为项目原创抽象资源。
- 不新增仿制宝可梦角色插画，不从来源不明的网站复制图标、纹理、音乐或音效。
- 新增外部资源时必须记录文件、来源、作者、许可证、修改情况和发布归属。
- Compatibility 渲染器为最低兼容目标；Shader 必须提供低画质降级路径。
- 功能不依赖悬停；触控目标不小于设计令牌定义的最小尺寸。
- 卡牌保持原始纵横比，20:9 通过增加留白与间距适配，不横向拉伸卡图。
- 强闪光、镜头震动和长距离移动在减少动画模式下禁用。

## 性能验收

- Windows 1600×900 High：目标稳定 60 FPS。
- 主流 Android 1080p Auto/High：目标 60 FPS。
- 中低端 Android Low：目标稳定 30 FPS。
- 连续三局后节点数量应恢复到基线；热缓存后的稳定内存增长不得超过 10%。
- 动画队列播放期间规则 revision、输入锁和最终显示状态必须保持一致。
- Android 结果记录在 `ANDROID_TEST_CHECKLIST.md`，包含设备型号、系统版本、画质档、平均/最低 FPS、峰值内存、温度和耗电。
