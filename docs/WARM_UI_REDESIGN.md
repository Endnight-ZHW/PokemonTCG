# 奶油暖色 UI

全游戏使用奶油米色、暖白面板、焦糖主操作与浅橡木／亚麻牌桌。范围包括标题、选牌、
联机、对战 HUD、所有弹窗、加载提示、行动日志和结算。页面接口、规则、协议、存档与
卡牌内容没有变化；没有新增主题切换设置。

## 视觉与维护

`godot/ui/design_tokens.gd` 是运行时语义颜色的来源，`FrontendPalette` 引用公共定义。
前台与对战的两个 `.tres` Theme 继续独立挂载，以保留编辑器预览、紧凑控件和既有布局。
主题回归检查序列化面板／文字与公共定义的一致性，并验证实际挂载按钮的各状态颜色。
更新公共调色板时，应同步 Theme、场景中的静态覆盖和固定颜色的 SVG 控件装饰。

| 角色 | 颜色 |
| --- | --- |
| 页面背景／面板 | `#F3EADB`／`#FFF9F0` |
| 正文／辅助文字 | `#45372F`／`#796757` |
| 主操作／选中来源 | `#A35F32` |
| 合法目标 | `#49786B` |
| 成功／危险 | `#4F7153`／`#AD5147` |
| 桌面／桌布 | `#C9A77E`／`#D9C9AD` |

卡图、卡背、能量属性色、特殊状态色和实体卡光照校准保留原样。主要按钮和 HP／伤害
徽章使用独立的 `TEXT_ON_ACCENT`，特殊状态使用深色 `STATUS_INK`；不要把背景色用作
徽章文字。卡牌富文本通过 `DesignTokens.rich_text()` 格式化静态模板，再插入转义后的
卡文，防止内容中的标记与主题占位符混用。可点击卡图和能量图标调用
`DesignTokens.preserve_art_icon()`，让所有按钮状态保留原图颜色；单色装饰图标继续使用深色墨色。

普通按钮圆角为 12px、面板 14px、弹窗 20px，使用低透明度暖棕阴影。主按钮与紧凑按钮
补齐了禁用、按下和悬停按下样式，状态切换不改变内边距。基础控件保持 48px 触控目标，
弹窗确认按钮为 56px。通用正文 18px，紧凑说明 16px，对战侧边详情正文提高到 14px。

## 界面与交互

- 首页调整模式入口之间的间距与标题／说明基线，保留横竖屏三维卡牌展示及静态降级。
- 选牌的焦糖浏览高亮与绿色已分配标签分开表达；两个玩家槽位仍允许分配同一套牌。
- 原生开关改为 40×24 的稳定轨道，滑杆增加清晰轮廓，下拉指示使用暖棕 SVG。滚动区域
  增加右侧留白，减少百分比、操作按钮与滚动条紧贴的问题。
- 牌桌采用浅木色和低反差亚麻纹理；战斗／备战区、卡牌轮廓、牌堆数量、竞技场标题及
  当前可用行动同步调整。卡图不应用全局暖色滤镜。
- 宽屏继续显示侧边卡牌详情，小屏通过详情入口阅读；保留动作浮层避让、选择进度、
  手牌浏览位置、逐层返回及强制选择。详情面板增加文字尺寸和状态区高度；牌桌可用高度
  小于 500px 时，牌堆不再向回合栏方向外移，避免安全区内的数量徽章被遮挡。
- 前台与对战普通弹窗分别使用 0.48／0.52 的暖棕遮罩，本地交接仍为完全不透明；
  弹窗关闭后恢复主题变体。所有交互阻断及取消权限仍由 `ModalHost` 管理。
- 保留原有动画策略，低画质或减少动画时停止装饰动画；没有增加常驻后处理或额外视口。

## 弹窗滚动整理

卡牌检查器取消卡文内部的固定高度和独立滚动，由弹窗统一滚动卡文、当前状态、进化链、
附着能量和道具。卡图保持顶部对齐和原有尺寸，关闭／返回按钮固定在底部。放大卡图或
查看附件后，恢复同一条阅读滚动位置。

选择弹窗使用 `PreviewScroll` 承载整块卡图与说明，文字按内容自然展开，避免说明内层与
弹窗外层同时出现竖向滚动条。选择进度、返回列表及确认按钮固定；切换卡牌时预览回到
顶部，返回选择列表时保留原滚动位置和已选项。宽屏的列表与预览仍是两个独立区域。

## 手牌对称与场上卡牌放大

双方手牌共用 `BattleHandFan3D` 的尺寸与圆弧参数，分别沿扇形平面层叠。对方手牌以同一扇形的相对
位置生成，补偿远侧透视并转向持牌者；卡背继续遮挡牌面。两侧使用独立的姿态缓存，
切换张数、窗口尺寸或摄像机状态时更新。对方手牌的显示上限由 8 张提高到 60 张，
数量徽章跟随实际扇形右侧，避免压住最后一张卡。

远侧卡牌分别沿平行平面定位，并预留实体卡厚度，避免 20 张以上卡背出现相交和条纹。

首次放大场上卡牌时，上下手牌带以桌布中线成对布置，使用两条手牌带之间的空间扩大
战斗区和备战区。这个版本将完整手牌压进窄带，卡面过小；现已改为下一节的贴边布局。
场上卡牌的放大幅度保留，堆叠能量和道具仍有独立间距。

对方检索卡牌返回手牌时，保持卡牌坐标轴正交以支持平滑姿态插值；旋转过程按投影宽度
控制尺寸，避免卡牌临时膨胀或落地跳位。密集手牌的图形交互测试改为从实际渲染边界
寻找露出的卡边，仍通过真实鼠标事件验证。

三维图形验证新增 1／5／7／10／20 张相同手牌的逐卡尺寸、位置、隐私和遮挡检查，并
验证五档窗口下战斗卡牌与备战卡牌都比上一版增大。性能场景提高为双方各 20 张手牌，
继续使用高／中／低画质 20ms／20ms／36ms 的原有 P95 门槛。

与上一版相比，1600×900、2000×900、2560×1392 的场上卡牌宽高增加约 22%，1280×720
增加约 17%，900×540 增加约 8%。[实际渲染前后对照](../build/hand-balance/compare.html)、
[同为 7 张手牌](../build/hand-balance/after/hands-7-1600x900.png)、
[同为 20 张手牌](../build/hand-balance/after/hands-20-1600x900.png)。

完整三维图形回归、界面图形回归、布局及交互回归通过。双方各 20 张手牌的性能实测
P95 为高 17.075ms／中 17.082ms／低 33.988ms，均满足原门槛；相同张数的对方卡背
另外验证实体层间不相交。[图形报告](../build/hand-balance/visual-validation.json)、

## 参考布局：大尺寸贴边手牌

按提供的卡牌游戏截图，将双方手牌放到屏幕上下边缘：卡牌放大，轻微倾斜并适度重叠，
下半部延伸到屏幕外；我方保留卡名和主要卡图的可见区域。扇形最大半角为 8°，增加
手牌时优先加大重叠程度，保留单卡尺寸。悬停抬起、选中、拖动和按原身份浏览继续生效。

回合栏移到左上，任务提示移到右上，中央留给对方手牌。紧凑窗口中回合与阶段分两行
显示，完整文字保留在工具提示和读屏说明中。对方数量徽章在会覆盖牌库的小屏上收起，
手牌数量仍显示在对方信息栏。菜单、详情和取消按钮保持原入口及触控尺寸。

桌布上下边距调整为相等，场上卡牌沿新的桌布中线整体居中。战斗区、备战区的尺寸独立
于手牌完整高度，避免放大手牌时再次缩小场上卡牌。原来顶部的多余空白转为我方手牌
的可见空间，手牌露出的边缘与最近一排备战区之间继续保留间隔。

`BattleHandFan3D` 将我方中立扇形围绕摄像机视轴旋转半周，再沿摄像机射线统一调整
深度，生成对方卡背。这样不仅尺寸和位置对称，实际四角轮廓也一致；共享的纸面平行
层级保持不相交，最低角高于桌面，避免放大的倾斜卡背被桌布切掉。卡背不持有私有卡图，
动画端点沿用相同的布局计算。双方手牌统一使用视口裁切及轻量接触阴影。

三维检查覆盖五档窗口和 1／5／7／10／20 张手牌，验证每张卡的可见高度至少 48px、
可见部分至少占完整高度的 40%、横向端卡不裁切，并逐卡验证露出的卡面可被射线选中。

## AI 思考高亮与卡牌对齐

修复 AI 思考效果仍读取旧二维 `CardView.position/size` 而产生的错位。三维对战中，
`AIThinkingOverlay` 保留状态文字、计时及动画节奏，将卡牌高亮交给 `CardEntity3D` 的
原生轮廓网格；轮廓与牌面共享同一个三维变换，随取景、尺寸、移动及隐藏同步更新。
只有 AI 已上场的卡牌显示思考高亮，空牌位使用牌桌原有边框，原来的二维矩形不再叠加。

选中、合法目标及悬停高亮优先于思考色，减少动画时保持静态。思考结束或卡牌被动画
隐藏时，高亮同步清除。原有 `configure(...)` 接口及独立二维场景的矩形绘制保持兼容。

扩展 `battle_3d_contract.gd`，覆盖五档分辨率、双方玩家身份、AI 本方视角、高／低画质、
减少动画、物理位置单独改变、遮挡和思考结束，检查轮廓投影误差低于 1px。
无界面及图形版三维契约、前台布局契约均通过，并检查了实际游戏渲染截图。
