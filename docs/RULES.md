# 宝可梦集换式卡牌游戏规则（中国大陆规则配置）

本项目以宝可梦中国大陆官方[玩法规则](https://www.pokemon.cn/tcg-rules-howtoplay)和
[进阶玩家向规则指南 Ver.3.1.0](https://www.pokemon.cn/tcg/pdf/basic_rules08.pdf)为主要裁决依据。
规则配置标识为 `CN_MAINLAND_3_1_0`。卡牌原文与通用规则冲突时，先按卡牌原文处理；同一时点有
多个效果时，按规则引擎给出的触发顺序完成选择。

## 本项目与官方赛事的边界

- 对局使用 60 张牌组、6 张奖赏卡和最多 5 只备战宝可梦。
- 保留项目现有 10 套预组，不在本轮强制检查赛制标记。中国大陆标准赛已按
  [官方轮换公告](https://www.pokemon.cn/tcg/other/22563.html)进入 G/H/I 环境；本项目不执行该
  轮换属于休闲卡池边界，不代表这些牌组都符合当前标准赛卡池。
- 官方规则会计算弱点和抗性；本项目把它们保留为对局选项，并且**默认关闭**。这是项目特例，
  不是官方规则。联机时由房主在开局前设置，挑战者只读确认，开局后锁定。
- 同批结算后双方达成相同数量且大于 0 的胜利条件时，本项目直接记录 `DRAW`，不进行一奖赏卡
  抢分赛。

## 牌组与卡牌

合法牌组必须满足：

- 恰好 60 张，并至少有 1 张基础宝可梦；所有卡牌 ID 都必须存在于当前卡池。
- 同名卡合计最多 4 张，不按卡牌 ID 分开计数；基本能量不受 4 张限制。
- ACE SPEC、光辉宝可梦等带有牌组数量限制的卡牌还必须满足各自限制。
- 当前使用的基本能量是草、火、水、雷、超、斗、恶、钢八种。无色是费用符号，不是基本能量；
  **不存在“龙基本能量”**。

宝可梦道具附着在宝可梦上，每只宝可梦通常最多附有 1 张。进化保留伤害、能量、道具和进化链，
但会清除特殊状态以及该宝可梦受到的临时招式效果。竞技场记录其所有者；不能打出与场上竞技场
同名的卡，即使卡牌 ID 不同。打出不同名竞技场时，旧竞技场弃置。

## 对战准备

1. 抛硬币。硬币获胜者在查看初始手牌前选择由哪名玩家先攻。
2. 双方洗牌，各抽 7 张牌。
3. 双方同时检查是否有基础宝可梦。没有基础宝可梦的一方公开手牌，将手牌洗回并重新抽 7 张；
   重复到可以设置为止。同一轮双方都再战时次数相抵，不给任何一方奖励；只有一方再战时，
   对手累计净奖励次数。
4. 按先攻玩家、后攻玩家的顺序，各自盖放 1 只基础宝可梦到战斗区，并可盖放基础宝可梦到
   备战区。任何一方完成前，对手只能看到严格的卡背占位，不能看到卡名、卡 ID 或日志暗示。
5. 双方各从牌库顶设置 6 张奖赏卡，盖放且不查看。
6. 有再战奖励的玩家选择额外抽 `0..N` 张，`N` 为净奖励次数。由奖励抽牌得到的基础宝可梦
   可以继续盖放到备战区，但不能替换战斗宝可梦，也不能超过备战区上限。
7. 所有设置和奖励放置完成后，双方场上宝可梦一次性翻开，进入先攻玩家的第一回合。

## 回合与首回合限制

每个回合先从牌库抽 1 张，然后进入主要阶段。**先攻玩家的第一回合也照常抽牌**。若回合开始
需要抽牌却牌库为空，完整结算后对手取得相应胜利条件。

主要阶段可按合法顺序执行：

- 从手牌将基础宝可梦放到备战区；不能用这个动作直接填补空战斗区。
- 进化场上宝可梦。自己的第一个回合不能进化；本回合刚上场或刚进化的宝可梦通常不能再次进化。
- 每回合通常从手牌手动附着 1 张能量卡。由卡牌效果附能不消耗这次手动附能机会，除非卡文另有说明。
- 使用物品、支援者、竞技场和宝可梦道具。支援者每回合最多 1 张，先攻玩家第一回合不能使用
  支援者；物品通常不限次数。
- 使用特性。主动特性按卡文和宝可梦实体分别记录；持续型和触发型特性不显示为任意时点的主动动作。
- 每回合通常撤退 1 次。支付撤退费用后，将战斗宝可梦与一只备战宝可梦互换。
- 选择一个招式攻击。先攻玩家第一回合不能攻击；攻击完整结算后回合结束。

因此，先攻玩家第一回合的限制是：不能通常进化、不能使用支援者、不能攻击；**没有“不抽牌”
限制**。后攻玩家第一回合可以使用支援者并攻击，但同样不能通常进化。

## 能量判定

- 无色费用可由任意类型能量单位支付；手动附能次数按“能量卡”计，不按能量单位计。
- 双重涡轮能量提供 2 个无色能量单位，其减伤效果按卡文在攻击方修正阶段处理。
- 夜光能量单独作为该宝可梦唯一的特殊能量时提供 1 个任意类型能量；只要该宝可梦还附有另一张
  特殊能量——包括第二张夜光能量——它就只提供 1 个无色能量。基础能量不会令夜光能量降级。
- 招式费用、撤退费用、按能量数量计算的公式和 AI 判断使用同一份有效能量视图。

## 伤害与招式结算

对每个攻击目标分别建立伤害结果，并严格按以下顺序计算：

1. 招式记载的基础伤害和公式结果。
2. 作用于攻击方宝可梦的增减伤效果。
3. 计算防守方的弱点。
4. 计算防守方的抗性。
5. 作用于防守方宝可梦的增减伤和防止伤害效果。
6. 结果不足 0 时按 0 处理，再同时放置本批次所有目标的伤害。

例如，基础 30 加攻击方修正 10 后再计算 ×2 弱点，结果是 80。基础 100 先受攻击方 -20，
再计算 ×2 弱点，最后受防守方 -30，结果是 130。对备战宝可梦的攻击伤害跳过弱点和抗性，
但仍经过攻击方、防守方及防止效果阶段。

“不计算弱点”“不计算抗性”“不受防守方伤害效果影响”是三个独立标记。忽略防守方伤害效果
不会关闭“受到伤害后”触发的幸运能量或特性。放置伤害指示物和直接令宝可梦昏厥不是攻击伤害，
不能伪装成伤害来触发或绕过相关效果；防止伤害、防止招式效果和防止全部效果也分别判定。

一个招式按下列时序完整处理：伤害前效果 → 全目标伤害批次 → 其余招式效果 → 受到伤害后触发
→ 昏厥触发 → 统一弃置 → 逐张取得奖赏卡及其触发 → 判定结果 → 必要时晋升 → 结束回合。
所有招式效果完成前不会在中途抢先判定胜负。

## 特殊状态与临时效果

| 状态 | 宝可梦检查时或行动时的处理 |
|---|---|
| 中毒 | 宝可梦检查时放置 1 个伤害指示物。 |
| 灼伤 | 宝可梦检查时放置 2 个伤害指示物，然后抛硬币，正面解除灼伤。 |
| 睡眠 | 不能攻击或撤退；宝可梦检查时抛硬币，正面醒来。 |
| 麻痹 | 不能攻击或撤退；在受影响方的下一个回合结束后的宝可梦检查中解除。 |
| 混乱 | 宣告攻击时抛硬币；反面则攻击失败，并在自身放置 3 个伤害指示物。 |

睡眠、麻痹、混乱互相替换；中毒和灼伤可以与它们及彼此共存。进化、撤退以及被效果强制移到
备战区时，会统一清除特殊状态和该宝可梦受到的临时招式效果，但保留伤害、能量、道具和进化链。
单纯在备战区与战斗区之间移动不伪造“回复 HP”；实际回复 0 点也不计为本回合回复过。

## 昏厥、奖赏卡和晋升

- 一个效果或伤害批次完成后，再统一检查所有宝可梦是否昏厥。宝可梦昏厥时，将该实体的进化链、
  能量和道具按规则弃置；多个学习装置、幸运能量等按实体逐个进入触发队列。
- 取得奖赏卡时，每一张都由玩家选择一个仍盖放的奖赏卡位置，不固定拿第 1 张，也不会在选择前
  暴露卡牌 ID。每张奖赏卡加入手牌前先处理其触发，例如宝藏能量可以选择不发动，或附着到己方
  战斗宝可梦/备战宝可梦。
- 同时昏厥时，先完成双方全部昏厥、触发、弃置和奖赏卡结算，再比较胜利条件。
- 若对局继续且双方都需要晋升，由**下一回合玩家**先选择新的战斗宝可梦，再由另一方选择。

引擎会记录昏厥来自攻击伤害、攻击效果、伤害指示物、特殊状态、特性或训练家等哪一类事实。
“上个对手回合”事实会在整个回应回合保持只读，不会被第一张查询它的卡牌消耗。

## 胜利与平局

常见胜利条件为：

1. 取得自己的全部奖赏卡。
2. 对手场上没有任何宝可梦。
3. 对手在必须从牌库抽牌时无法抽牌。

只在完整效果、昏厥和奖赏卡批次结束后统计双方各自达成的条件数。一方条件数更多时该方获胜；
双方条件数相同且都大于 0 时，结果为 `DRAW` 且 `winner=-1`。平局不会暗中指定“当前玩家”
为胜者；训练奖励双方都是 0，评估计分双方各 0.5。
