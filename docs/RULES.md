# 宝可梦集换式卡牌游戏 (PTCG) 核心规则

## 规则校准（2026-05-30）
- 主要阶段只能从手牌将基础宝可梦放到备战区；战斗区空缺时只能从备战区晋升。若一方场上没有任何宝可梦，则其对手获胜。
- 自己的第一回合不能进化；先攻玩家第一回合不抽牌、不能使用支援者、不能攻击。
- 每回合一次限制包括：手动附着能量、撤退、使用支援者、打出 Stadium、发动可手动使用的特性，以及发动可主动使用的 Stadium 效果。
- 不能打出与场上同名的 Stadium。打出新的不同名 Stadium 时，旧 Stadium 进入弃牌区。
- passive、on_enter_play、on_damaged 等触发/持续型特性不作为手动动作出现；手动特性按宝可梦实例记录，每个自己的回合最多使用一次，并在自己的回合开始重置。
- 攻击解析完成后，规则上只能结束回合；UI 可以保留攻击展示阶段，但不能继续执行主阶段动作。

## 一、基本设置

| 项目 | 数值 |
|------|------|
| 卡组数量 | 60张（同名卡最多4张） |
| 初始手牌 | 7张 |
| 奖品卡 | 6张 |
| 备战区上限 | 5只 |
| 能量附着 | 每回合1次 |
| 支援者使用 | 每回合1次 |
| 撤退 | 每回合1次 |

## 二、卡牌类型

1. **宝可梦卡**: Basic、Stage 1、Stage 2、ex/V/VMAX 等
2. **训练家卡**: Item(物品)、Supporter(支援者)、Stadium(竞技场)、Tool(宝可梦道具)
   - **物品卡**：每回合使用次数不限
   - **支援者卡**：每回合最多1张
   - **竞技场卡**：全场同时只能有1张，新卡打出时旧卡送入弃牌区
   - **宝可梦道具**：附着于宝可梦身上，每只宝可梦最多1张。进化时保留已附着的能量和宝可梦道具；宝可梦被击倒或离场时，再按对应效果处理附着卡
3. **能量卡**: 基本能量、特殊能量

## 三、能量类型系统

- **基本能量类型**：火、水、草、雷、超、斗、恶、钢、龙
- **无色能量需求**：可用任意属性能量支付
- **特殊能量**：提供特殊效果的能量卡。例如：
  - 双重涡轮能量：提供2个无色能量，但伤害-20
  - 喷射能量：附着于备战区宝可梦时自动切换至战斗区
  - 夜光能量（彩虹能量）：可作为任意属性能量使用，但若同一宝可梦身上有其他特殊能量，则降级为无色能量

## 四、对战准备

1. **抛硬币决定先后攻**
2. 双方洗牌
3. 各抽7张手牌
4. 若无基础宝可梦：洗回牌库重抽7张（再战），对手可多抽1张
5. 放置1只基础宝可梦到战斗区（盖放）
6. 可选放置最多5只基础宝可梦到备战区（盖放）
7. 从牌库顶取6张作为奖品卡（盖放）
8. 双方翻开场上所有宝可梦

> 硬币投掷必须在设置开始前进行，因为先后手会影响玩家的策略选择。

## 五、回合结构

### 抽牌阶段
- 从牌库抽1张卡
- **重要：先攻玩家的第一个回合不抽牌**

### 主要阶段（以下动作可按任意顺序进行）
1. 打出基础宝可梦到备战区
2. 进化宝可梦（不能进化当回合上场的宝可梦，不能在自己的第一回合进化）
3. 附着1个能量（从手牌→宝可梦）
4. 使用训练家卡
   - 物品卡：不限次数
   - 支援者卡：每回合1张（先攻第一回合不能使用）
   - 竞技场卡：全场只能有1张
   - 宝可梦道具：每只宝可梦最多附有1张
5. 使用特性
6. 撤退（支付撤退费用，将战斗宝可梦与备战宝可梦互换）

### 攻击阶段
- 选择1个招式并攻击
- 攻击后回合结束，进入宝可梦检测

### 先手第一回合限制（完整清单）
先攻玩家的第一回合不能执行以下操作：
- 不能抽牌（跳过抽牌阶段）
- 不能进化
- 不能使用支援者卡
- 不能攻击

后攻玩家的第一回合无以上限制。

## 六、伤害计算

伤害计算顺序：
1. 基础伤害
2. 计算弱点（通常 ×2）
3. 计算抵抗力（通常 -20 或 -30）
4. 应用其他修正效果（特性、道具、竞技场等增减伤）
5. 最小为 0

### 属性克制/抵抗开关
本项目默认不计算属性弱点和抵抗力。主页面可开启“属性克制/抵抗”开关；本地对战按该开关执行，联机对战按主机设置执行，AI 挑战模式固定关闭。

### 贯穿伤害
部分招式具有贯穿效果——不计算弱点和抗性，直接造成基础伤害（不受伤害减免和免疫效果影响）。

## 七、特殊状态

| 状态 | 效果 | 恢复方式 |
|------|------|---------|
| 中毒 | 宝可梦检测时放置1个伤害指示物 | 进化、撤退、特殊卡效果 |
| 灼伤 | 宝可梦检测时放置2个伤害指示物，抛硬币正面治愈 | 进化、撤退、硬币正面 |
| 睡眠 | 不能攻击/撤退，卡牌逆时针旋转90° | 宝可梦检测时抛硬币正面醒来 |
| 麻痹 | 不能攻击/撤退，卡牌顺时针旋转90° | 宝可梦检测时自动恢复（自身下一回合结束后） |
| 混乱 | 攻击时抛硬币，反面则自身放置3个伤害指示物且攻击失败，卡牌旋转180° | 进化、撤退 |

### 状态互斥规则详解

**旋转互斥组（睡眠、麻痹、混乱）**：这三种状态互相排斥。当宝可梦已处于其中一种状态时，若被施加另一种同组状态，则旧状态被新状态替代（卡牌只能处于一种旋转方向）。

**标记共存组（中毒、灼伤）**：使用实体标记表示，可与所有其他状态共存（包括旋转互斥组状态），彼此之间也可共存。即一只宝可梦可以同时处于"中毒+灼伤+睡眠"状态。

- **进化时**清除所有特殊状态
- **撤退或切换至备战区时**清除所有特殊状态
- 备战区宝可梦不受特殊状态影响

## 八、宝可梦检测（回合间处理）

每个回合结束时（攻击后），对双方场上宝可梦依次处理：
1. 中毒伤害（放置1个伤害指示物）
2. 灼伤伤害及恢复判定（放置2个伤害指示物，抛硬币判定治愈）
3. 睡眠恢复判定（抛硬币判定醒来）
4. 麻痹自动恢复（若为受影响方的下一回合结束后）
5. 检查昏厥（剩余HP归零的宝可梦送入弃牌区）

## 九、胜利条件

满足以下任一条件即获胜：
1. 获得全部6张奖品卡
2. 对手场上没有任何宝可梦（战斗区和备战区均无）
3. 对手回合开始时牌库无法抽卡

## 十、昏厥处理

1. 宝可梦HP归零 → 送入弃牌区（含所有附着卡：能量、道具、进化前形态）
2. 对手获得奖品卡（基础宝可梦=1张，ex/GX/V=2张，VMAX/TAG TEAM=3张）
3. 若战斗宝可梦昏厥，从备战区选择新的战斗宝可梦
4. 若场上已无宝可梦 → 对手直接获胜

## 十一、特殊规则

1. **ACE SPEC**：卡组中最多1张
2. **光辉宝可梦**：卡组中最多1张
3. **ex宝可梦**：昏厥时对手获得2张奖品卡
4. **先攻第一回合限制**：先攻玩家不可抽牌、不可进化、不可使用支援者、不可攻击
5. **进化限制**：不能进化当回合上场的宝可梦，不能在自己的第一回合进化
6. **同名卡规则**：同名卡在一个卡组中最多4张（基本能量卡不在此限）
7. **神奇糖果**：允许基础宝可梦跳过1阶进化直接进化为2阶，但受第一回合和当回合上场限制
