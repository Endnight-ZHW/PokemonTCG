# 三维实体卡牌对战

对战使用 Godot 4.7 Compatibility，Windows 与 Android 共用一个真实三维牌桌。
首页、选牌、大厅和完整卡牌检查器继续使用现有 UI。规则引擎、Native ABI、网络协议、
存档及原始卡图没有变更。

## 场景与数据边界

`BattleTable` 是原有会话与交互入口，内部的 `PhysicalTable` 承载独立 `SubViewport`、
`BattleWorld3D`、透视相机、木桌、织物牌垫、灯光及三维反馈。桌面与手机分别使用约
55° / 65° 俯角，相机按安全区内的可用尺寸重新构图。

屏幕布局、手势与 HUD 保留 Control 语义锚点；其二维卡图与装饰不参与牌桌绘制。
`BattleProjection3D` 统一完成屏幕、世界、射线与包围区域转换。分辨率降档只作用于
三维 Viewport，不改变 UI 分辨率或拾取坐标。手牌裁切在卡牌材质中完成，物理高度
区分重叠卡牌；卡牌正反面与纸边合并为一次绘制，使用共享圆角薄片网格。

`CardMotionEntity` 拥有独立视觉身份、`Transform3D` 起止姿态和 `CardEntity3D` 引用。
它的 Control 部分是屏幕锚点，不再包含二维飞牌图像、阴影或纸边节点。拖拽会话保留
原有动作版本与提交状态，并记录实体姿态；普通飞牌、完整宝可梦及附件的换位、翻牌、
落桌、硬币和反馈均在世界中显示。原二维牌垫绘制及二维镜头驱动已移除。

规则事件与 `MotionHandle` / `PresentationHandle` 决定表现顺序和完成时机。隐藏目标
仍更新几何，保证新抽入但尚未揭示的手牌具有正确落点。重同步、失焦、取消和退出
沿用现有协调器；实体池释放正面纹理。本地交接立即清理上一玩家的三维实体。

视图经过玩家投影后才进入表现层，预加载也会过滤事件的可见性。后续卡图通过线程加载，
协调器等待可见资源准备好再开始该批动画；该等待可取消，且不修改规则状态或 RNG。
硬币的实体朝向只展示规则提供的结果。

## 默认设置

新配置默认使用标准动画。已有电影化、快速或减少动画的选择仍有效。

| 画质 | 帧率 | 三维比例 | MSAA | 主光阴影 |
| --- | ---: | ---: | --- | --- |
| 高 | 60 | 100% | 4× | 2048 |
| 中 | 60 | 85% | 2× | 1024 |
| 低 | 30 | 75% | 关闭 | 接触阴影 |

Windows 对局自动使用高档，Android 自动从中档开始。预热后每五秒统计前台帧时间；
连续三个窗口的 P95 超过 22ms 时，待当前动作完成再降到低档。当前对局不自动回升，
手动档位不受干预，降档不会写入用户设置。资源准备、开局、失焦、暂停及尺寸重建不计入采样。

卡图使用 mipmap 和各向异性过滤，原始图片保持不变。单个牌堆最多展示六层卡片，
场上附件最多展示六个露出的层次，HUD 和规则选择仍保留完整数量与物理索引。
空闲实体池上限 48，三维反馈同时最多六组。页面隐藏时停止三维渲染并释放实体表。

## 开发与验证

在 Godot 中运行 `res://tools/ui_workbench.tscn`（F6），原有抽牌、出牌、进化、换位、
击倒、公开展示、硬币与速度模式按钮现在直接驱动三维牌桌。

```powershell
.\tools\test_godot.ps1
.\tools\test_godot_ai.ps1
.\tools\test_godot_network.ps1
.\tools\test_battle3d_graphics.ps1
.\tools\build_godot.ps1 -Target all -Configuration debug
```

图形验证使用实际显示设备，拒绝 shader 错误和运行时警告；无图形模式不能代替它。
`battle_3d_contract` 还覆盖投影与射线、多分辨率、裁切、隐藏正面、隐藏落点、实体池、
物理飞牌、硬币结果、自动降档、反复进出场景和退出时取消资源等待。

截图输出到 `build/ui-preview/`。性能探针在满备战区、20 张手牌、多附件、重复四张飞牌
与命中反馈下分别测量三个档位，结果保存到 `build/battle3d-performance.json`；
可修改探针采样长度做持续测试。60 帧档 P95 门槛为 20ms，30 帧档为 36ms。

Android 调试导出和模拟输入验证不等同于真机测试。尚需在连接的真实 Android 设备上
验证触控、持续帧率、切换后台后的恢复和温升；未取得这些数据前，不宣称手机性能已达标。

已通过完整 Godot 契约、10 套 Challenge 卡组终局回归、LAN 与 Relay 同牌组完整对局、
